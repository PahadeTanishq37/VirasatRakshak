# Digital Bharat HeritageVerse

A comprehensive React.js application that celebrates India's rich cultural heritage through immersive digital experiences. Built with modern web technologies and inspired by vibrant Indian culture.

## 🌟 Features

### 🏠 HomePage
- Hero section with animated elements
- Feature showcase with interactive cards
- Statistics display
- Call-to-action sections

### 🗺️ Interactive Map
- 3D map visualization of Indian heritage sites
- Site filtering and search functionality
- Detailed site information modals
- Interactive markers and navigation

### 📚 AI Storytelling
- AI-powered heritage stories
- Audio narration with controls
- Chapter-based content
- Interactive storytelling features

### 🎮 Gamified Quests
- Heritage-themed games and challenges
- XP and coin reward system
- Achievement tracking
- Multiple game categories

### 📱 Augmented Reality
- AR try-on experiences
- 3D object placement
- Interactive AR controls
- Traditional attire and artifacts

### 🛍️ Artisan Marketplace
- Authentic Indian handicrafts
- Direct artisan support
- Product filtering and search
- Shopping cart functionality

## 🎨 Design System

### Color Palette
- **Saffron**: `#f97316` - Inspired by the Indian flag
- **Peacock Blue**: `#0ea5e9` - Representing peacock feathers
- **Marigold Yellow**: `#facc15` - Traditional festival color
- **Heritage Gold**: `#FFD700` - Royal and luxurious
- **Royal Purple**: `#4B0082` - Regal and majestic

### Typography
- **Display Font**: Playfair Display (for headings)
- **Body Font**: Inter (for content)
- **Devanagari**: Noto Sans Devanagari (for Hindi text)

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd digital-bharat-heritageverse
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🛠️ Technologies Used

- **React 18** - Modern React with hooks
- **Vite** - Fast build tool and dev server
- **React Router** - Client-side routing
- **TailwindCSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Lucide React** - Beautiful icon library
